# FluxAgent 工程结构

基于 2026-11-02 本地仓库扫描。项目为单模块 Maven / Spring Boot 后端，没有前端子工程；接口可通过 Swagger、HTTP 或 CLI 使用。

```text
FluxAgent/
├── pom.xml                         # 构建、依赖管理、可执行 Jar
├── mvnw / mvnw.cmd / .mvn/         # Maven 3.9.9 启动脚本及随仓库提供的发行包
├── src/main/java/com/echomind/
│   ├── EchoMindJavaApplication.java # 应用入口
│   ├── api/                        # HTTP 接口、Swagger、请求响应 DTO
│   ├── chat/                       # HTTP / CLI 共用聊天业务与请求指标
│   ├── cli/                        # 交互终端、会话切换与退出
│   ├── agent/                      # 多 Agent 路由、专属 Agent、回答验证
│   ├── config/                     # 配置绑定、异步、调度、OpenAPI
│   ├── intent/                     # Jev 分类客户端、多来源识别兜底、实体与紧急度
│   ├── knowledge/                  # 文档切分、JSON 存储、Hybrid RAG
│   ├── llm/                        # 模型网关、Spring AI 与本地降级
│   ├── memory/                     # Redis 工作记忆、情景记忆、画像
│   ├── tool/                       # 知识检索编排、通用工具执行与熔断
│   ├── skill/                      # SKILL.md 解析、匹配、动态加载
│   ├── evaluation/                 # 意图与回答评估、基线回归
│   └── monitor/                    # 指标采集、告警、路由表现反馈
├── src/main/resources/application.yml # 应用默认配置及模型 profile
├── src/test/java/                  # 自动化测试
├── .env.example                    # 无真实密钥的模型配置示例；本地 .env 不入库
├── skills/                         # 通用客服、账单、技术支持提示词
├── config/                         # Nginx / Prometheus 部署配置
├── Dockerfile / docker-compose.yml # 镜像与依赖服务部署
├── rules/                          # 工程说明
└── .changes/                       # 本次范围、设计、实施与验证记录
```

| 技术 | 构建文件版本/实现 |
| --- | --- |
| Java | 21 |
| Spring Boot | 3.5.0 |
| Spring AI | 1.1.0，Anthropic / DeepSeek |
| LangChain4j | 1.12.2，Spring starter 1.12.2-beta22 |
| Springdoc | 2.8.17 |
| JSON Schema | networknt 2.0.0 |
| 存储 | Redis 工作记忆；JSON 知识库、情景记忆、画像 |
| 观测 | Actuator / Micrometer / Prometheus |
| 测试 | Spring Boot Test / JUnit Jupiter / Mockito / AssertJ |

业务依赖方向：入口 → 聊天流程 → 记忆、意图、知识检索与 Agent → 模型网关及存储。工具执行器只提供执行控制，不依赖 HTTP。监控读取编排及工具统计，反馈路由惩罚。知识检索采用本地 BM25 与 hash vector，不需要 ChromaDB；现有 VectorStore 仅为可选写入适配。

默认通过 DMXAPI 调用 `deepseek-v4.1-flash-1017` 生成回复，通过独立的 `JevIntentClient` 调用 `jev-latest` 做意图分类；低置信度或服务不可用时使用既有识别器。Java/Maven 启动可选导入工作目录 `.env`，Compose 使用 env_file，主模型和 Jev 默认共用本地 `DMX_API_KEY`。

初始仓库只有 main 分支及少量初始化提交，没有在途 Change 或测试。README 列出的 CLI、通用工具管理和监控增强是明确的补全项。ChromaDB 主检索属于可选规划，当前没有 Embedding 模型配置；前端与远程 MCP 协议也没有开发中实现。

保留 `com.echomind` 包名和 `echomind.*` 配置键，避免更名破坏调用与部署兼容性。根包外的 `Main.java` 是独立练习代码，与业务入口无关。
